# numbeat
Hello guys, it's an numbeat repo.
## What is numbeat?
numbeat it's music formulas what use:
1. Numbers from 1 to 9
2. Operators (+ - * /)
3. Functions (sin(), tan(), cos(), sqrt())
4. string literals ("text", CharCodeAt())
## How work numbeat?
Numbeat work's generating an audio wave with Sample Rate (in KhZ)
The beat generation using bytebeat but without "t"
